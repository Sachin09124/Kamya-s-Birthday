# 🎂 Happy Birthday Kamya 💗

A beautiful interactive birthday surprise website created using HTML, CSS, and JavaScript.

## ✨ Features

- 💖 Beautiful Welcome Screen
- 🎁 Open Surprise Button
- ❤️ Floating Hearts Animation
- 🎂 Birthday Cake
- 🕯️ Candles with Lighting Effect
- 💨 Blow Candles Animation
- 🎈 Floating Balloons
- 🎊 Confetti Celebration
- 🎁 Animated Gift Box
- 💖 Glowing Heart
- 💌 Typewriter Birthday Message
- 🌸 Falling Flowers
- ⭐ Sparkling Stars
- 🌙 Moon and Moving Clouds
- 🎆 Fireworks
- 🎵 Birthday Music
- 🔄 Replay Surprise Button

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 📂 Project Structure

```
Birthday-Card/
│── index.html
│── style.css
│── script.js
│── music.mp3
│── README.md
```

## 🚀 How to Run

1. Download or clone the repository.
2. Open the project folder.
3. Double-click `index.html` or open it in your browser.
4. Click **🎁 Open Surprise** and enjoy!
